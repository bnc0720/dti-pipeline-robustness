# Data availability note

The file `all_pipelines_tractometry_features_master.csv` contains **derived
tractometry summary measures** (per subject × pipeline × tract × metric × feature)
computed from diffusion-MRI data obtained from the **Alzheimer's Disease
Neuroimaging Initiative (ADNI)** database (adni.loni.usc.edu).

These data are subject to the **ADNI Data Use Agreement (DUA)** and therefore
**cannot be redistributed openly** in this repository. To obtain the underlying
imaging data, researchers must apply for access directly at
https://adni.loni.usc.edu/data-samples/access-data/ and agree to the DUA.

The derived tractometry table used here can be shared with ADNI-approved
researchers upon request, or re-derived from ADNI source images using the
preprocessing pipelines and the code in this repository.

> Before public release, confirm with the ADNI DUA whether the derived
> subject-level table may be deposited (e.g., to the LONI/IDA derived-data area
> or a controlled-access repository), and update the manuscript's Data and Code
> Availability statement accordingly.
